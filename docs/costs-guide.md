# دليل التكاليف — من الخام إلى ربح الحفلة

> السلسلة في سطر واحد:
> **وارد** (سعر) ← **إنتاج** (خصم + تكلفة) ← **صنف أكل** (باركود) ← **حفلة** (عرض) ← **منصرف** (خصم + تحميل) ← **إرجاع/تالف** (تصحيح) ← **ربحية**.

---

## أولاً: الترتيب خطوة بخطوة

### ١. تسجيل الصنف
**التكاليف ← أصناف التكاليف ← «تسجيل صنف جديد»**

اسم + **وحدة ثابتة** (كيس، تنك، كجم…) + باركود (من المورد أو مولّد داخلياً) + تاريخ إنتاج/انتهاء اختياري.

> ⚠️ الوحدة **تُقفَل** بعد أول عملية وارد. تغييرها بعدها — كجم إلى شوال مثلاً — يجعل كل وصفة تشير للصنف خاطئة بخمسين ضعفاً بصمت.

### ٢. إدخال الوارد
**التكاليف ← الوارد**

الصنف (مسح باركود أو **اختيار من القائمة**) + المورد + الكمية + **السعر قبل الضريبة** + تاريخ الفاتورة.

الرصيد يرتفع، ويُحسب:

```
متوسط سعر التكلفة = مجموع (الكمية × السعر) ÷ مجموع الكميات
```

وهذا المتوسط هو الرقم الذي يسعّر كل ما بعده — الإنتاج والصرف والتالف.

### ٣. الدمج = الإنتاج
**التكاليف ← الإنتاج**

اختر الصنف المُنتَج (أو أنشئه هنا فيُولَّد له **باركود داخلي**)، ثم أضف الخامات وكمياتها، واكتب **كمية الإنتاج** وتاريخي الدفعة (من / إلى).

في **معاملة واحدة**:
- يُخصم كل خام من رصيده
- يدخل المُنتَج المخزون بتكلفة = مجموع تكاليف مدخلاته
- تكلفة الوحدة = الإجمالي ÷ كمية الإنتاج
- يُطبع ملصق الدفعة: **الفريج** ← التاريخ من/إلى ← اسم الصنف ← الباركود

> ⚠️ اكتب كمية الإنتاج الحقيقية. كتابة «١ صحن» تجعل تكلفة الصحن الواحد = كل الخامات المستهلكة، وهذا الرقم ينتقل مباشرة إلى ربحية الحفلة.

الحذف يعكس العملية كاملة: ترجع الخامات ويُخصم المُنتَج وقيمته.

### ٤. الربط بأصناف الأكل
**أصناف الأكل ← عدّل القسم ← «من التكاليف والإنتاج» ← اختر المُنتَج**

يصير صنف أكل مرتبطاً بباركوده، فتُقرأ تكلفته ورصيده تلقائياً.

> ⚠️ الافتراضي **وحدة واحدة لكل طبق**. إن كان الواقع غير ذلك عدّله من زر الوصفة، وإلا خرج حساب التكلفة والمتوفر مضخّماً أو منقوصاً بصمت.

الاسم المكرر يُميَّز بالباركود، لأن نفس الاسم قد يكون خلطتين مختلفتين في قسمين (بطاطس المشويات غير بطاطس البروستد) بتكلفتين مختلفتين.

### ٥. إنشاء الحفلة
عند اختيار صنف الأكل وكميته يظهر تحته:
- **المطلوب مقابل المتوفر** — أحمر عند النقص
- **التكلفة التقديرية** لكل الأصناف المختارة

> هذه **قراءة فقط**. لا يُخصم شيء من المخزون بمجرد إنشاء الحفلة أو تأكيدها.

### ٦. الصرف الفعلي
**التكاليف ← المنصرف**

الصنف + الكمية (متوسط السعر يُعبَّأ تلقائياً وقابل للتعديل) + **القسم = الحفلات** + **اسم العميل** + تاريخ الصرف.

هنا **ينزل الرصيد فعلاً**، وتُقيَّد التكلفة **على تلك الحفلة تحديداً**.

> الصرف باسم مكتوب يدوياً لا يُحمَّل على أي حفلة — ولذلك تظهر لك قيمته مجمَّعة كتنبيه في أعلى الصفحة وفي صفحة الربحية.

### ٧. التسوية بعد الإلغاء
**زر ↩ على عملية المنصرف**

| الحالة | النتيجة |
|---|---|
| أُلغيت **قبل** الصرف | لا شيء خرج — **لا خسارة** |
| أُلغيت والخلطة **صالحة** | إرجاع ← ترجع للرصيد وتُلغى من تكلفة الحفلة |
| أُلغيت والخلطة **تلفت** | تالف + السبب ← **خسارة عامة**، لا تكلفة حفلة |
| **استُهلكت** فعلاً | تبقى تكلفة على الحفلة |

التسوية تقبل الجزئية وعلى دفعات، مع منع تجاوز المتبقي.
وصفحة **التالف** تسجّل أيضاً تلف المستودع مباشرة (انتهاء صلاحية، كسر، سوء تخزين) فيُخصم من الرصيد بمتوسط سعره.

### ٨. الربحية
**ربحية الحفلات** — المدير ومن يُمنح الصلاحية فقط.

```
الربح = الصافي قبل الضريبة − (خامات التكاليف + مواد الموارد الخارجية
                              + تكلفة القاعة + فواتير المصروفات)
```

وبنود تُعرض **ولا تُحتسب** على الحفلات:
- قيمة المواد الداخلية المستخدمة (أصول مملوكة ترجع بعد الحفلة)
- خامات صُرفت باسم مكتوب يدوياً
- **خسارة التالف**
- خسارة الحفلات الملغاة

## ثانياً: مثال كامل بالأرقام — العميل «أبو سعد»

### ١. الوارد

| الصنف | العملية | الكمية | السعر قبل الضريبة | القيمة |
|---|---|---|---|---|
| بطاطس | فاتورة ١ | 10 كيس | 20 | 200 |
| بطاطس | فاتورة ٢ | 10 كيس | 30 | 300 |
| زيت | فاتورة ٣ | 4 تنك | 120 | 480 |

```
متوسط بطاطس = (200 + 300) ÷ 20 = 25 ريال/كيس
متوسط زيت   = 480 ÷ 4        = 120 ريال/تنك
```

### ٢. الإنتاج — «بطاطس مقلي»

المدخلات: 4 كيس بطاطس + 1 تنك زيت

```
بطاطس:  4 × 25  = 100
زيت:    1 × 120 = 120
                ─────
إجمالي التكلفة   = 220 ريال
كمية الإنتاج     = 100 صحن
تكلفة الصحن      = 220 ÷ 100 = 2.20 ريال
```

الأرصدة بعد الإنتاج:

| الصنف | قبل | بعد |
|---|---|---|
| بطاطس | 20 كيس | **16 كيس** (خُصم 4) |
| زيت | 4 تنك | **3 تنك** (خُصم 1) |
| بطاطس مقلي | — | **100 صحن** بقيمة 220 (متوسط 2.20) |

### ٣. الربط
قسم «المشويات» ← بطاطس مقلي — الوصفة: **1 صحن لكل طبق**.

### ٤. الحفلة — السعر 10,000 شامل ضريبة 15%

```
الصافي قبل الضريبة = 10,000 ÷ 1.15 = 8,695.65
الضريبة            = 10,000 − 8,695.65 = 1,304.35
```

عند اختيار **بطاطس مقلي × 80 طبق** يظهر:

> المطلوب 80 / المتوفر 100 صحن ✔ — التكلفة التقديرية **176 ريال** (80 × 2.20)

### ٥. الصرف

```
80 صحن × 2.20 = 176 ريال  →  تُقيَّد على أبو سعد
رصيد بطاطس مقلي = 100 − 80 = 20 صحن
```

### ٦. الربحية

| البند | المبلغ |
|---|---|
| الصافي قبل الضريبة | 8,695.65 |
| − خامات التكاليف | 176.00 |
| − سيارة مؤجرة (500 شامل ← 500 ÷ 1.15) | 434.78 |
| − إيجار عمالة | 800.00 |
| − مواد الموارد الخارجية | 300.00 |
| **إجمالي التكاليف** | **1,710.78** |
| **الربح** | **6,984.87** |

## ثالثاً: لو أُلغيت الحفلة بعد الصرف

رجعت **50 صحن صالحة** وتلفت **30 صحن** — اضغط ↩ على عملية المنصرف:

```
المرتجع  50 صحن → رصيد بطاطس مقلي = 20 + 50 = 70 صحن
التالف   30 × 2.20 = 66 ريال → «خسارة التالف»
المستهلك 80 − 50 − 30 = 0 صحن
تكلفة الخامات على الحفلة = 0.00 ريال  (كانت 176)
```

| أين يظهر الرقم | المبلغ |
|---|---|
| خسارة التالف (بند مستقل، ليس على حفلة) | **66.00** |
| خسارة الحفلة الملغاة = التكاليف المتبقية (0 + 434.78 + 800 + 300) + المسترد للعميل (مثلاً 2,000) | **3,534.78** |

**الفرق الذي صنعته التسوية:** لولاها لبقيت الـ 176 ريال كلها محمّلة على الحفلة الملغاة، ولبقيت الـ 50 صحن خارج المخزون رغم صلاحيتها — أي خسارة وهمية 110 ريال ونقص وهمي في الرصيد.

## مرجع سريع

| أريد أن… | الصفحة |
|---|---|
| أسجّل صنفاً أو أطبع ملصقه | التكاليف ← أصناف التكاليف |
| أُدخل مشتريات بأسعارها | التكاليف ← الوارد |
| أدمج خامات في خلطة وأولّد لها باركود | التكاليف ← الإنتاج |
| أصرف خامات على حفلة | التكاليف ← المنصرف |
| أُرجع أو أسجّل تالفاً | التكاليف ← المنصرف (زر ↩) أو التكاليف ← التالف |
| أرى الأرصدة | التكاليف ← رصيد الأصناف |
| أربط الخلطة بصنف أكل | أصناف الأكل ← تعديل القسم |
| أرى ربح كل حفلة | ربحية الحفلات |

### قواعد لا تُكسر

1. **الوحدة تُقفَل** بعد أول وارد.
2. **كمية الإنتاج الحقيقية** لا «١» — تكلفة الوحدة تنتقل للربحية كما هي.
3. **الوصفة تُعدَّل** بعد ربط الصنف بالأكل (الافتراضي 1:1).
4. **اختر الحفلة من القائمة** لا تكتب اسمها يدوياً، وإلا لم تُحمَّل التكلفة على أحد.
5. **التالف يُسجَّل بسببه** — وإلا ظهر التلف وكأنه استهلاك على الحفلة.
