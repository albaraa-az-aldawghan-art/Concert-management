# سجل النشاطات

يظهر آخر خمسة نشاطات أسفل لوحات التحكم، والسجل الكامل في `/admin/activity`.
البحث يشمل اسم المنفّذ وبريده والإجراء والمرجع. التصفية الزمنية بتوقيت الرياض.

## الصلاحية

من **الموظفون ← الأدوار والصلاحيات ← الدور المطلوب ← سجل النشاطات**، فعّل أو أوقف فتح الصفحة.
الإذن مستقل عن لوحة التحكم ويعمل للأدوار الجاهزة والمخصصة. المدير يملك الإذن دائماً.
الواجهة تخفي السجل دون الإذن، والخادم يعيد فحص الإذن في كل طلب. لا يملك المتصفح قراءة
مجموعة `activity_logs` أو الكتابة عليها مباشرة، ولا توجد واجهة لتعديل السجل أو حذفه.

## التسجيل

- `handle` يحجز سجلاً دائماً بعد التحقق من هوية المستخدم وقبل تنفيذ العملية، ثم يحدّث نتيجته.
- العمليات المالية والحفلات والموارد والطلبات والتعاقدات والمستخدمون والصلاحيات والإعدادات
  والمسودات تدخل عبر هذا المسار. الملفات المصدّرة تستخدم `withActivityResponse` للحفاظ على رد الملف.
- أسماء المستخدمين وبريدهم تؤخذ من قاعدة البيانات وقت الإجراء. لا تُقبل هوية المنفّذ من جسم الطلب.
- تفاعلات المتصفح تشمل الأزرار والروابط والاختيارات والملفات والتنقل والطباعة. تظهر بصفتها
  **تفاعل بالواجهة**؛ لا تعتبر دليلاً على نجاح تعديل. لا تُقرأ قيم حقول النص وكلمات المرور.
- تسجيل الخروج هو **طلب تسجيل الخروج**، لأن إنهاء جلسة Firebase يحدث في المتصفح لاحقاً.
- استخدام رابط تصدير دائم يُنسب إلى الرابط، لا إلى منشئه؛ زائر PDF دون جلسة يظهر كزائر غير مسجل.
- تُحذف query strings من المسار، ولا تحفظ أجسام الطلبات أو كلمات المرور أو مفاتيح التصدير.
- تتكرر محاولة إنهاء السجل ثلاث مرات؛ عند فشلها يبقى **النتيجة غير مؤكدة**، ولا يتحول تنفيذ
  مالي ناجح إلى رسالة فشل تدفع المستخدم لتكراره. فشل الحجز الأولي يمنع بدء العملية.
- تفاعلات المتصفح تستخدم معرّفات ثابتة عند إعادة المحاولة حتى لا تتكرر أو تتغير تواريخها.
  لا يمكن ضمان وصول تفاعل متصفح عند انقطاع الشبكة أو إغلاق المتصفح قسرياً؛ سجل عمليات الخادم مستقل عنه.
- يبدأ التسجيل عند تفعيل النسخة الجديدة؛ لا يُنشئ تاريخاً سابقاً لم يكن مسجلاً.

## النشر والتحقق

انشر نسخة التطبيق ثم قواعد `firestore.rules` المرافقة. نقل الإعدادات والأدوار والمسودات إلى
الخادم يتطلب نشر الاثنين؛ القواعد القديمة تسمح بتجاوز التسجيل عبر كتابات مباشرة.
لا يلزم فهرس مركّب جديد: الترتيب بالتاريخ ومعرّف المستند، والبحث يفحص دفعات محدودة مع مؤشر متابعة.
بطاقة اللوحة تتحدث كل 15 ثانية أثناء ظهور الصفحة.

التحقق المحلي:

```sh
npm test
npm run build
node scripts/test-activity-ui.mjs
```

اختبارات الخادم تستخدم بدائل معزولة لـ Firebase ولا تعدّل بيانات المشروع.
اختبار المتصفح يشغّل المكونات الفعلية مع هوية وبيانات تجريبية، ويفحص الجوال والكمبيوتر
والبحث والتصفية وإخفاء السجل ومنع كشف الحقول الحساسة. مسار Chrome قابل للتحديد بـ `CHROME_PATH`.
